# Gridcrest Website

A responsive bilingual (English / Simplified Chinese) static website built with HTML, CSS and vanilla JavaScript.

## Run locally
- Unzip the package.
- Open `index.html` in a modern browser; no build step or server is required.
- For local development, you may also run `python -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Deploy
Upload the complete folder contents to any static hosting provider (for example, your web host, Cloudflare Pages, Netlify, or an S3-compatible static website bucket).

## Customize
- `index.html`: page structure and content.
- `styles.css`: visual design and responsive breakpoints.
- `script.js`: bilingual copy and interactions.
- `assets/`: local SVG brand mark and favicon.

## Notes
This is an enhanced, independently authored implementation based on the Gridcrest brand direction and AI-era energy infrastructure positioning. The reference website could not be retrieved as machine-readable source during production, so this package should be treated as a polished rebuild rather than a pixel-perfect source-code duplicate. Review all company descriptions, contact details, project claims and legal wording before publishing. The email `info@gridcrest.us` is a suggested general contact and should be confirmed before launch.
